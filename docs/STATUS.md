# d4-build2filter — статус

**Где мы.** Работает: **https://onlyterrore.github.io/d4-build2filter/**
Вставляешь ссылку на билд с d4builds — получаешь код лут-фильтра.

**Все 11 аффиксов билда владельца подтверждены живой игрой** (21.09). На его билде страница
собирает 13 правил: база, подсветка под билд по слотам, прятки. 34 теста зелёные.

Кодировщик воспроизводит экспорт игры **побайтово** — на двух эталонах: чужом фильтре
maxroll и экспорте из игры владельца.

**Следующий шаг.** Снять id типов вещей (9 штук) тем же приёмом — тогда подсветка перестанет
цеплять лишние предметы. Сейчас она работает без ограничения по типу: подсвечивает больше
нужного, но ничего не теряет.

Открывай только карточки со статусом 🔵 или 🟡. ⚪ читай, когда до неё дошла очередь.
✅ и ⏸ не открывай без прямой просьбы владельца.

**Что узнали о самой игре 21.09** (пригодится для чеклиста Switch)

- Экран называется `LOOT FILTER`, две панели: `SELECTED LOOT FILTER` и `RULE EDITOR`.
- Кнопки: `New Filter`, `Add Rule`, `Enable All`, `Disable All`, счётчик правил `N / 25`.
- Меню `...` рядом с выбором фильтра: `Rename`, `Duplicate`, `Export`, `Delete`.
- В правиле: `Add Condition`, `VISIBILITY`, колонки `CONDITION` / `PROPERTY`.
- Условие на аффиксы: `Has Optional Affixes`, счётчик — `Must have at least [N] of the selected affixes`.
- Внизу подсказка: `An item must meet ALL of a rule's conditions to apply`.
- Разделы в выборе аффиксов: `OFFENSIVE`, `DEFENSIVE`, `UTILITY`, `RESOURCE`, `MOBILITY`.
- Галочка `Show All Classes` скрывает чужие классовые аффиксы (Strength, Dexterity и прочие).

**Известная шероховатость**

После обновления сайта браузер минут десять держит старый модуль в кэше и может показывать
прошлый результат. Справочники id читаются с `no-cache` и обновляются сразу; код — нет.
Лечится жёсткой перезагрузкой. Если станет мешать — версионировать импорты.

**Ждёт владельца**

- Снять id типов вещей — минут десять в игре, тем же способом.
- Скриншот меню фильтра на Switch 2, если консольный интерфейс отличается от ПК.
