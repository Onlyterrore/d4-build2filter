# d4-build2filter — статус

**Где мы.** Страница работает локально: вставляешь ссылку на билд с d4builds — получаешь код
лут-фильтра. 30 тестов зелёные. Кодировщик воспроизводит экспорт игры **побайтово** — это
проверено на чужом рабочем фильтре. Наружу ничего не опубликовано.

**Следующий шаг.** Решение владельца: публиковать ли репозиторий на GitHub (задача 14).
После публикации — круг сверки id на живой игре (задача 15), без него фильтр умеет прятать
мусор, но не подсвечивает вещи под билд.

Открывай только карточки со статусом 🔵 или 🟡. ⚪ читай, когда до неё дошла очередь.
✅ и ⏸ не открывай без прямой просьбы владельца.

| Задача | Статус | Где |
|---|---|---|
| Спека | ✅ принято | `docs/specs/2026-09-21-...-design.md` |
| План работ | ✅ принято | `docs/plans/2026-09-21-...-core.md` |
| Задачи 1–13: каркас, кодек, чтение билда, правила, три страницы | ✅ принято | 13 коммитов |
| Задача 14: публикация на GitHub Pages | 🟡 ждёт владельца | нужно согласие на публичный репозиторий |
| Задача 15: круг сверки id на живой игре | ⚪ не начата | нужен ПК с игрой |
| Чеклист для Switch 2 | ⏸ парковка | заблокирован до скриншота меню игры |
| Автообновление карты витринных билдов | ⏸ парковка | второй план |

**Ждёт владельца**

- Публиковать ли репозиторий публично на GitHub? Без этого страницы по ссылке не будет.
- Скриншот меню лут-фильтра на Switch 2 — иначе подписи в чеклисте будут выдуманы.
- Круг сверки id: собрать в игре фильтры с одним признаком и прогнать через `verify.html`.

**Посмотреть локально**

```
python -m http.server 8099
```
и открыть `http://localhost:8099/`
