# d4-build2filter — статус

**Где мы.** Работает целиком: **https://onlyterrore.github.io/d4-build2filter/**
Вставляешь ссылку на билд с d4builds — получаешь код лут-фильтра.

На билде владельца: **13 правил, ноль непереведённых свойств, ноль неопознанных типов вещей.**
Восемь правил подсветки — по одному на слот, каждое ограничено своим типом вещи.
35 тестов зелёные, 22 коммита.

Кодировщик воспроизводит экспорт игры **побайтово** на двух эталонах: чужом фильтре maxroll
и экспорте из игры владельца.

**Следующий шаг.** Выяснить, почему игра при импорте молча выбрасывает три аффикса
(Maximum Resource, Wrath Regeneration, Resistance to All Elements) на бронеслотах.
Версии перечислены в `FINDINGS.md`. Порог по умолчанию снижен до 1, чтобы выброс
не ужесточал правила.

Открывай только карточки со статусом 🔵 или 🟡. ⚪ читай, когда до неё дошла очередь.
✅ и ⏸ не открывай без прямой просьбы владельца.

**Что подтвердилось замерами в игре**

- Порядок условий в списке игры совпал с номерами 0–9 в `src/constants.js`.
- Счётчик аффиксов означает «не меньше N» (`Must have at least [N] of the selected affixes`).
- Условия внутри правила складываются по «И».
- Офф-хенд чернокнижника называется `Focus`.
- Таблица сообщества за 13 сезон **непригодна**: подписи смещены непостоянно.
- Групповой экспорт непригоден: порядок id не совпадает ни с экраном, ни с кликами.
- На d4builds опечатка `All Damage Multipler` — лечится списком синонимов.

**Известная шероховатость**

После обновления сайта браузер минут десять держит старый модуль в кэше. Справочники id
читаются с `no-cache` и обновляются сразу, код — нет. Лечится жёсткой перезагрузкой.

**Ждёт владельца**

- Скриншот меню фильтра на Switch 2, если консольный интерфейс отличается от ПК.
