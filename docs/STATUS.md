# d4-build2filter — статус

**Где мы.** Проект заведён 2026-09-21. Страница на GitHub Pages: вставляешь ссылку на билд
с d4builds.gg — получаешь лут-фильтр Diablo 4 (код импорта для ПК и чеклист для Switch 2).
Ссылку можно раздать друзьям. Кода ещё нет — написана спека, версия 2.

Разведка 21.09 показала, что билды d4builds читаются открытым запросом с любого сайта и
содержат человеческие названия свойств. Поэтому закладку из версии 1 убрали: страница
забирает билд сама.

**Следующий шаг.** Владелец выбирает способ исполнения плана. Первая задача — каркас
репозитория и первый коммит.

Открывай только карточки со статусом 🔵 или 🟡. ⚪ читай, когда до неё дошла очередь.
✅ и ⏸ не открывай без прямой просьбы владельца.

| Задача | Статус | Где |
|---|---|---|
| Спека инструмента | ✅ принято | `docs/specs/2026-09-21-d4-build2filter-design.md` |
| План работ, ядро (15 задач) | 🟡 ждёт владельца | `docs/plans/2026-09-21-d4-build2filter-core.md` |
| Каркас, кодек, страница, публикация | ⚪ не начата | задачи 1–14 плана |
| Круг сверки id на живой игре | ⚪ не начата | задача 15 плана |
| Чеклист для Switch 2 | ⏸ парковка | заблокирован до скриншота меню игры |
| Автообновление карты витринных билдов | ⏸ парковка | второй план |

**Ждёт владельца**

- Вычитать раздел «Решения, принятые за вас» в спеке — там 8 пунктов, решённых без вас.
- Нужен скриншот меню лут-фильтра на Switch 2: иначе подписи в чеклисте будут выдуманы.
- Нужен ПК с игрой для круга сверки id — без него таблицы остаются неподтверждёнными.
