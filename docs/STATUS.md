# d4-build2filter — статус

**Где мы.** Опубликовано и работает: **https://onlyterrore.github.io/d4-build2filter/**
Вставляешь ссылку на билд с d4builds — получаешь код лут-фильтра. Проверено на живом адресе,
включая телефонную ширину. 30 тестов зелёные, 14 коммитов.

Кодировщик воспроизводит экспорт игры **побайтово** — проверено на чужом рабочем фильтре.

**Следующий шаг.** Круг сверки id продолжается: подтверждён 1 аффикс из 11
(`Critical Strike Chance` = 1829582), типы вещей ещё не начаты. На билде владельца
страница уже собирает 8 правил вместо 5.

Первый же экспорт из игры вскрыл два расхождения в кодировщике — игра не пишет пустое
имя правила и использует `HAS_OPTIONAL_AFFIXES`. Оба исправлены, экспорт лежит вторым
эталоном. Вывод: каждый новый экспорт проверять на побайтовое совпадение.

Открывай только карточки со статусом 🔵 или 🟡. ⚪ читай, когда до неё дошла очередь.
